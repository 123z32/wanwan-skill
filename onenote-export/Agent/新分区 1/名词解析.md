名词解析
 
 
 
 
 

 
LLM大模型

 
 

 | Token 大模型处理数据的最基本单位
 | 平均0.75英文单词一个token
 | 1-2个中文一个token
 
 

 
Context 大模型每次处理任务时接收到的信息总和

 
Context Window 大模型的Context最多可以能够存储的Token量

 
Prompt 用户或系统当前给大模型下达的具体指令与问题 User Prompt or System Prompt

 
Tool 大模型用来感知和影响外部环境的函数与工具

 
MCP 统一了函数与工具接入格式的标准协议

 
Agent （智能体）能自主规划和调用工具，直到解决用户问题的程序

 
Agent Skill 给Agent（智能体）看的说明文档
