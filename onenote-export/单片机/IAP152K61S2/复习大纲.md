# 复习大纲

> 来源: OneNote > 单片机 > IAP152K61S2
> 修改: 2025-06-11T14:35:22Z

复习大纲
 
 
 
 
 

 
一、电路基础（难度：1-3）

 
 
- 
电路基本概念

 
 
- 欧姆定律、基尔霍夫定律
 
- 串联 / 并联电路分析
 
- 电压、电流、电阻、功率的计算
 

 
 
- 
交流电路基础

 
 
- 正弦交流电的三要素（幅值、频率、相位）
 
- 电容 / 电感对交流信号的影响（容抗、感抗）
 

 
 
- 
电路分析方法

 
 
- 戴维南定理、叠加定理的应用
 

 
 

 
二、C51 编程基础（难度：1-3）

 
 
- 
C 语言核心语法

 
 
- 数据类型（char/int/float）、运算符、流程控制（if/for/while）
 
- 数组、指针、函数定义与调用
 
- 结构体与枚举类型的使用
 

 
 
- 
单片机编程基础

 
 
- I/O 口操作（位操作、寄存器配置）
 
- 头文件包含（如STC15F2K61S2.H）
 
- 中断函数编写（interrupt关键字）
 

 
 
- 
模块化编程

 
 
- 函数封装（如数码管显示、按键扫描）
 
- 头文件与源文件分离（.h/.c结构）
 

 
 

 
三、电子元件基础知识（难度：1-3）

 
 
- 
被动元件

 
 
- 电阻、电容、电感的参数识别与选型
 
- 上拉电阻、去耦电容的作用
 

 
 
- 
半导体元件

 
 
- 二极管（整流、稳压）、三极管（放大、开关作用）
 
- LED 指示灯、光敏电阻的特性与应用
 

 
 
- 
机电元件

 
 
- 继电器、按键、蜂鸣器的驱动电路
 

 
 

 
四、数模电路（难度：1-4）

 
a) 数制与编码（难度：3）

 
 
- 二进制、十进制、十六进制的相互转换
 
- BCD 码、ASCII 码的编码规则
 

 
b) 二极管、三极管、基础门电路（难度：1-3）

 
 
- 二极管 / 三极管的伏安特性与电路分析
 
- 与门、或门、非门的逻辑表达式与真值表
 
- 组合逻辑电路设计（如编码器、译码器）
 

 
c) 运算放大器、滤波器（难度：1-4）

 
 
- 运放的虚短 / 虚断原理
 
- 放大电路（同相 / 反相放大）、加法 / 减法电路
 
- RC 滤波电路（低通 / 高通）的频率特性
 

 
d) AD、DA 转换（难度：1-4）

 
 
- 模数转换（ADC）原理（逐次逼近法）
 
- 数模转换（DAC）原理（权电阻网络）
 
- PCF8591 等典型芯片的 I2C 通信控制
 

 
e) 电源转换（难度：2-4）

 
 
- 三端稳压器（如 7805）的应用
 
- DC-DC 降压 / 升压电路原理
 
- 电源滤波与抗干扰设计
 

 
五、工具仪表使用（难度：1-5）

 
 
- 
万用表

 
 
- 测量电压、电流、电阻的方法
 
- 二极管导通电压检测
 

 
 
- 
示波器

 
 
- 波形观测（幅值、频率、占空比）
 
- 触发模式设置（边沿触发）
 

 
 
- 
信号发生器

 
 
- 正弦波 / 方波 / 三角波的输出设置
 

 
 
- 
编程器 / 烧录器

 
 
- 单片机程序烧录流程（如 STC-ISP 软件）
 

 
 

 
六、IAP15F2K61S2 单片机（难度：3-5）

 
a) 外设（难度：3-4）

 
 
- 定时器 / 计数器（T0/T1）的模式配置（定时 / 计数模式）
 
- 中断系统（外部中断、定时器中断）
 
- 串口通信（UART）的波特率计算与数据收发
 
- 数码管动态扫描驱动（通过 P2 口控制锁存器）
 

 
b) 性能与工作参数（难度：3-4）

 
 
- 内部振荡器配置（12MHz 晶振）
 
- 存储空间（Flash/EEPROM/RAM）的使用
 
- 低功耗模式（空闲模式、掉电模式）
 

 
c) 典型应用场景（难度：3-5）

 
 
- 工业控制（继电器、电机驱动）
 
- 传感器数据采集（超声波、温湿度）
 
- 人机交互（按键输入、数码管 / LCD 显示）
 

 
七、通信总线（难度：4）

 
a) SPI

 
 
- 通信协议特点（全双工、主从模式）
 
- 时序图分析（时钟极性 CPOL、相位 CPHA）
 
- 典型器件（如 W25Qxx Flash）的驱动
 

 
b) UART/RS485/RS232

 
 
- 串口通信参数（波特率、数据位、停止位、校验位）
 
- RS485 的差分传输与抗干扰优势
 
- 电平转换芯片（如 MAX232/MAX485）的应用
 

 
c) I2C

 
 
- 总线时序（起始 / 停止信号、应答机制）
 
- 多设备寻址（7 位从机地址）
 
- 典型器件（PCF8591、AT24C02）的读写操作
 

 
d) 1-Wire

 
 
- 单总线协议特点（单根数据线）
 
- DS18B20 温度传感器的初始化与数据读取
 

 
八、传感器应用（难度：4-6）

 
 
- 
物理量传感器

 
 
- 超声波传感器（测距原理、回波时间计算）
 
- 光敏电阻 / 红外对管（光强检测）
 

 
 
- 
环境传感器

 
 
- DHT11 温湿度传感器（单总线通信）
 
- 气压传感器（如 BMP280，I2C 接口）
 

 
 
- 
信号处理

 
 
- 传感器数据滤波（均值滤波、中值滤波）
 
- 模数转换结果的校准与线性化
 

 
 

 
学习建议

 
 
- 
理论与实践结合：

 
 
- 先掌握 C51 编程和单片机外设原理，再通过开发板实操（如数码管显示、按键控制）。
 

 
 
- 
重点突破难点：

 
 
- 通信总线（I2C/SPI）和传感器应用是高频考点，需熟练编写驱动代码。
 

 
 
- 
模拟赛题训练：

 
 
- 参考蓝桥杯历年真题，练习多任务协作（如按键 + 显示 + 传感器同步运行）。
 

 
 
- 
工具熟练使用：

 
 
- 学会用示波器观测时序（如 I2C 波形），用万用表排查电路故障。
