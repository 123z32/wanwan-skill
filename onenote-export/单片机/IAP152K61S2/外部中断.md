外部中断
 
 
 
 
 

 

 
外部中断0初始化，这里举例下降沿触发

 
void Int0Init()

 
{

 
 EX0=1;//允许Int0中断

 
 IT0=1;//下降沿触发,即按下瞬间触发

 
}

 
外部中断1初始化，这里举例低电平触发

 
void Int1Init()

 
{

 
 EX1=1;//允许Int0中断

 
 IT1=0;//低电平触发,即按下持续期间触发

 
}

 
//中断号，外部中断0是0，定时器0是1，外部中断1是2，定时器1是3。如果忘记查阅手册

 
//主函数要写EA=1;开启总中断
