工作区变量
 
 
 
 
 

 

 

 

 
工作区包含在 MATLAB® 中创建或从数据文件或其他程序导入的变量。例如，下列语句在工作区中创建变量 A 和 B。

 
A = magic(4);￼B = rand(3,5,2);

 

 
使用 whos 可以查看工作区的内容。

 

 
Whos

 

 

 
Name Size Bytes Class Attributes￼

 
A 4x4 128 double 

 
B 3x5x2 240 double 

 
此外，桌面上的“工作区”面板也会显示变量。

 ![The panel has a row for each variable. The columns are Name, Value, Min, and Max. Value includes size and class.](https://graph.microsoft.com/v1.0/users('2209338213@qq.com')/onenote/resources/0-5d762ba5c1244571bb9324648f96763a!1-9E53C6D99C1E5AD1!s9b2a8b4df63c4848a74ddbd7d74f0041/$value)
 
退出 MATLAB 后，工作区变量不会保留。使用 save 命令保存数据以供将来使用，

 
save myfile.mat

 

 
通过保存，系统会使用 .mat 扩展名将工作区保存在当前工作文件夹中一个名为 MAT 文件的压缩文件中。

 
要清除工作区中的所有变量，请使用 clear 命令。

 
使用 load 将 MAT 文件中的数据还原到工作区。

 
load myfile.mat
