# 📝 学习日志 - 2026-04-02

## 🔧 遇到的问题

### 问题 1: 忘记主动执行每日备份

**问题描述**:
- 今天完成了发票整理和发票管家 skill 创建
- 做完后没有主动执行每日 Git 备份
- 等用户张提醒"怎么没有备份，昨天"才想起来补上

**根本原因**:
- 专注在具体任务上，忽略了每日例行任务
- 没有在工作完成后检查 HEARTBEAT.md 的每日任务清单

**解决方案**:
- 建立检查清单习惯
- 每天工作完成后主动检查：
  1. 总结今天的工作
  2. Git 备份
  3. 更新长期记忆
  4. 说晚安

**影响**:
- 用户需要主动提醒，体验不好
- 违背了"主动执行"的原则

## 💡 学到的东西

### 1. 发票整理工作流
- PDF 解析使用 pdftotext 工具
- 图片发票使用 image 工具 OCR 识别
- 飞书文档整理需要保持格式一致
- 金额校验很重要（发票 vs 行程单）

### 2. Skill 创建经验
- 支持多种输入格式（PDF + 图片）
- 命重要贴用户场景（发票管家 vs invoice-organizer）
- 不一定要发布到 ClawHub，自己用着舒服就好

### 3. 工作流程优化
- 多行程发票按行程单分别列出
- 报销人不确定时先问用户
- 开票人≠报销人，不需要管开票人

---

## 📖 经验总结

1. **主动执行 > 被动提醒** - 每日备份等例行任务应该主动完成
2. **检查清单很重要** - 工作完成后对照清单逐项检查
3. **用户期望管理** - 昨天做到了，今天也应该做到
