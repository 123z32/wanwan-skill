## 📊 Modbus 寄存器映射

### 从站信息
| 参数 | 值 |
|------|-----|
| **IP 地址** | `192.168.1.13` (局域网) |
| **端口** | `5020` |
| **从站地址** | `1` |

### 寄存器表

#### 1️⃣ 线圈 (Coils) - 功能码 01/05/15

| 地址 | 名称 | 读写 | 说明 |
|------|------|------|------|
| `0x0000` | LED_Control | 读写 | LED 控制 (1=ON, 0=OFF) |

#### 2️⃣ 离散输入 (Discrete Inputs) - 功能码 02

| 地址 | 名称 | 读写 | 说明 |
|------|------|------|------|
| `0x0000` | LED_Status | 只读 | LED 实际状态反馈 |
| `0x0001` | Light_Status | 只读 | 光敏电阻状态 (1=亮，0=暗) |

#### 3️⃣ 保持寄存器 (Holding Registers) - 功能码 03/06/16

| 地址 | 名称 | 读写 | 说明 |
|------|------|------|------|
| `0x0000` | Light_Value | 只读 | 光敏电阻原始值 (0/1) |
| `0x0001` | Uptime | 只读 | 运行时间 (秒) 低 16 位 |

#### 4️⃣ 输入寄存器 (Input Registers) - 功能码 04

| 地址 | 名称 | 读写 | 说明 |
|------|------|------|------|
| `0x0000` | Light_Value | 只读 | 光敏电阻原始值 |
| `0x0001` | Uptime | 只读 | 运行时间 (秒) |

## 🧪 测试命令

### 使用 modbus-cli

```bash
# 安装
sudo apt-get install -y modbus-cli

# 读线圈 (LED 控制状态)
modbus tcp 192.168.1.13 -p 5020 read coils 0 1

# 写线圈 - LED ON
modbus tcp 192.168.1.13 -p 5020 write coil 0 1

# 写线圈 - LED OFF
modbus tcp 192.168.1.13 -p 5020 write coil 0 0

# 读离散输入 (LED 状态 + 光敏电阻)
modbus tcp 192.168.1.13 -p 5020 read discrete 0 2

# 读保持寄存器 (光敏电阻值 + 运行时间)
modbus tcp 192.168.1.13 -p 5020 read holding 0 2

# 读输入寄存器
modbus tcp 192.168.1.13 -p 5020 read input 0 2
```

### 使用 Python 测试

```python
from pymodbus.client import ModbusTcpClient

client = ModbusTcpClient('192.168.1.13', port=5020)
client.connect()

# 打开 LED
client.write_coil(0, True, slave=1)

# 读取离散输入
result = client.read_discrete_inputs(0, 2, slave=1)
print(f"LED 状态：{result.bits[0]}")
print(f"光敏电阻：{result.bits[1]}")

# 读取保持寄存器
result = client.read_holding_registers(0, 2, slave=1)
print(f"光敏电阻值：{result.registers[0]}")
print(f"运行时间：{result.registers[1]} 秒")

client.close()
```

## 🔧 故障排查

### 问题 1: 端口被占用

```bash
# 查看占用端口的进程
sudo lsof -i :5020

# 杀死旧进程
sudo pkill -f gpio_led_light_modbus_service.py

# 重启服务
sudo python3 gpio_led_light_modbus_service.py
```

### 问题 2: GPIO 初始化失败

**原因**: 程序未在树莓派宿主机运行

**解决**: 
- 确保在树莓派上运行（不是 Docker 容器）
- 或使用模拟模式（自动降级）

### 问题 3: LabVIEW 连接失败

**检查**:
```bash
# 测试端口
telnet 192.168.1.13 5020

# 查看服务日志
tail -f /tmp/scada.log

# 检查防火墙
sudo ufw status
```
