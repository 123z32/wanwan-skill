## 🚀 快速恢复（推荐）

### 前提条件

1. **SSH Key**（用于 GitHub 认证）
   ```bash
   # 在目标机器上生成 SSH key
   ssh-keygen -t ed25519 -C "zhang@github" -f ~/.ssh/github_key -N ""
   
   # 将公钥添加到 GitHub
   cat ~/.ssh/github_key.pub
   # 复制输出内容到 GitHub → Settings → SSH and GPG keys
   ```

2. **OpenClaw 环境**
   - 已安装 OpenClaw（参考官方文档）
   - 已配置飞书应用（App ID + App Secret）

---

### 步骤 1：克隆备份仓库

```bash
# 创建工作目录
mkdir -p /opt/openclaw-workspace
cd /opt/openclaw-workspace

# 克隆备份仓库
git clone git@github.com:123z32/wanwan-skill.git .
```

---

### 步骤 2：配置 OpenClaw

```bash
# 编辑 OpenClaw 配置文件
nano ~/.openclaw/openclaw.json
```

**关键配置项：**

```json
{
  "models": {
    "providers": {
      "qwen": {
        "baseUrl": "https://coding.dashscope.aliyuncs.com/v1",
        "apiKey": "sk-sp-xxxxxxxxxxxxx"
      }
    }
  },
  "channels": {
    "feishu": {
      "enabled": true,
      "appId": "cli_xxxxxxxxxxxxx",
      "appSecret": "xxxxxxxxxxxxxxxxxxxxx"
    }
  },
  "agents": {
    "defaults": {
      "workspace": "/opt/openclaw-workspace"
    }
  }
}
```

---

### 步骤 3：配置 SSH（用于 Git 推送）

```bash
# 创建 SSH 配置
cat >> ~/.ssh/config << 'EOF'
Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/github_key
  IdentitiesOnly yes
EOF

# 添加 GitHub 到已知主机
ssh-keyscan github.com >> ~/.ssh/known_hosts 2>/dev/null

# 测试连接
ssh -T git@github.com
# 应显示：Hi 123z32! You've successfully authenticated
```

---

### 步骤 4：启动 Gateway

```bash
# 启动 OpenClaw Gateway
openclaw gateway

# 或者后台运行（systemd）
openclaw gateway install
systemctl --user start openclaw-gateway.service
```

---

### 步骤 5：验证恢复

```bash
# 检查状态
openclaw status

# 检查 Git 状态
cd /opt/openclaw-workspace
git status

# 测试飞书连接
# 在飞书中发送消息给助手
```

## 🔧 详细恢复步骤（按需）

### A. 恢复工作区文件

```bash
# 如果 Git 克隆失败，手动复制文件
cp -r /backup/wanwan-skill/* /opt/openclaw-workspace/

# 关键文件：
# - IDENTITY.md（助手身份）
# - USER.md（用户信息）
# - MEMORY.md（长期记忆）
# - HEARTBEAT.md（定时任务）
# - memory/（工作日志）
# - templates/（发票模板）
# - onenote-export/（笔记导出）
```

### B. 恢复 Git 历史

```bash
cd /opt/openclaw-workspace

# 初始化 Git
git init

# 添加远程仓库
git remote add origin git@github.com:123z32/wanwan-skill.git

# 拉取历史
git fetch origin

# 重置到最新提交
git reset --hard origin/master

# 验证
git log --oneline -5
```

### C. 配置飞书应用

1. **登录飞书开放平台**：https://open.feishu.cn/
2. **创建企业自建应用**
3. **获取凭证**：
   - App ID
   - App Secret
4. **配置权限**：
   - 消息
   - 群组
   - 机器人
5. **启用 WebSocket**（推荐）或 Webhook

## 📦 备份策略

### 自动备份（每日 0:00）

```bash
# HEARTBEAT.md 中配置的自动备份任务
cd /opt/openclaw-workspace

# 添加更改
git add -A

# 提交
git commit -m "📝 Daily summary: $(date +%Y-%m-%d)"

# 创建标签
git tag -a backup-$(date +%Y-%m-%d) -m "Daily backup"

# 清理旧标签（保留最近 3 个）
git tag -l | sort | head -n -3 | xargs git tag -d

# 推送
git push origin main --tags
```

### 手动备份

```bash
# 随时可以手动备份
cd /opt/openclaw-workspace
git add -A
git commit -m "💾 Manual backup: $(date +%Y-%m-%d-%H-%M)"
git push origin master
```

## 🛠️ 故障排查

### 问题 1：Git 推送失败

**错误：** `fatal: could not read Username for 'https://github.com'`

**解决：**
```bash
# 改用 SSH
git remote set-url origin git@github.com:123z32/wanwan-skill.git

# 或者配置 HTTPS 凭证
git config --global credential.helper store
```

---

### 问题 2：飞书消息不响应

**检查：**
```bash
# Gateway 状态
openclaw gateway status

# 插件状态
openclaw plugins list

# 日志
tail -f /tmp/openclaw/openclaw-*.log
```

**解决：**
```bash
# 重启 Gateway
openclaw gateway restart

# 或者重新安装插件
openclaw plugins reinstall feishu
```

---

### 问题 3：记忆搜索不可用

**检查：**
```bash
# 测试 Ollama 连接
curl http://100.100.145.74:11434/api/tags

# 检查 embedding 模型
curl http://100.100.145.74:11434/api/show -d '{"name":"nomic-embed-text"}'
```

**解决：**
```bash
# 拉取 embedding 模型
ollama pull nomic-embed-text

# 或者使用云端 embedding
# 编辑 ~/.openclaw/openclaw.json，配置 DashScope API
```
