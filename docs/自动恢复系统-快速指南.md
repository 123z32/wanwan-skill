## 📋 常用命令

### 查看状态

```bash
# Gateway 状态
bash scripts/supervisor.sh status

# 查看健康检查日志
tail -f logs/cron-healthcheck.log

# 查看 Gateway 日志
tail -f logs/gateway.log
```

### 重启服务

```bash
# 重启 Gateway
bash scripts/supervisor.sh restart

# 完全重启（Gateway + 健康检查）
bash scripts/supervisor.sh stop
kill $(cat /tmp/openclaw-healthcheck.pid) 2>/dev/null || true
bash scripts/start-all.sh
```

### 停止服务

```bash
# 停止 Gateway
bash scripts/supervisor.sh stop

# 停止健康检查
kill $(cat /tmp/openclaw-healthcheck.pid) 2>/dev/null || true
```

## 🔍 故障排查

### Gateway 崩溃了怎么办？

**不用管！系统会自动恢复～**

健康检查守护进程会在 5 分钟内发现并自动重启 Gateway。

如果想手动恢复：
```bash
bash scripts/auto-heal.sh
```

### 如何确认系统在运行？

```bash
# 1. 检查 Gateway 进程
ps aux | grep openclaw-gateway | grep -v grep

# 2. 检查健康检查进程
ps aux | grep healthcheck-daemon | grep -v grep

# 3. 查看 PID 文件
cat /tmp/openclaw-gateway.pid
cat /tmp/openclaw-healthcheck.pid
```

### 查看自动恢复日志

```bash
# 查看最近的恢复记录
tail -20 logs/auto-heal.log

# 查看所有异常
grep -E "❌|⚠️|ERROR|WARN" logs/cron-healthcheck.log | tail -20
```

## 🎯 配置说明

### 修改检查频率

编辑 `scripts/healthcheck-daemon.js`:

```javascript
// 第 10 行
const CHECK_INTERVAL = 5 * 60 * 1000; // 5 分钟

// 改为 1 分钟
const CHECK_INTERVAL = 1 * 60 * 1000;

// 改为 10 分钟
const CHECK_INTERVAL = 10 * 60 * 1000;
```

### 修改警报阈值

编辑 `scripts/cron-healthcheck.sh`:

```bash
# 第 33 行 - 磁盘警报阈值
if [ "$DISK_USAGE" -gt 85 ]; then  # 85%

# 第 40 行 - 内存警报阈值
if [ "$MEM_AVAILABLE" -lt 500 ]; then  # 500MB
```

## 🆘 紧急救援

### 如果所有脚本都失效...

**手动重启 Gateway**:
```bash
pkill -f openclaw-gateway
cd /home/node/.openclaw/workspace
openclaw gateway &
```

**手动恢复配置**:
```bash
cd /home/node/.openclaw/workspace
git fetch origin
git reset --hard origin/master
```

**完全重建**:
```bash
cd /home/node/.openclaw/
rm -rf workspace
git clone https://github.com/123z32/wanwan-skill.git workspace
cd workspace
bash scripts/start-all.sh
```
