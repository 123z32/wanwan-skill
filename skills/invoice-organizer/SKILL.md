# invoice-organizer - 发票整理技能

## 描述
自动解析和整理各类发票（打车、餐饮、酒店、机票、高铁等），提取关键信息并整理到飞书云文档表格。

## 触发条件
- 用户发送发票 PDF 文件
- 用户发送行程单 PDF 文件
- 用户发送发票图片（JPG/PNG 等）
- 用户提到"发票"、"报销"、"整理发票"等关键词

## 支持的发票类型

### 1. 打车发票（网约车/的士）
**提取字段**：
- 发票号码
- 开票日期
- 服务商（曹操出行、及时用车、如祺出行等）
- 金额（价税合计）
- 出行人
- 行程数

**行程单字段**：
- 上车时间
- 城市
- 起点
- 终点
- 车型
- 金额

### 2. 高铁票
**提取字段**：
- 车次
- 出发站
- 到达站
- 出发时间
- 座位号
- 金额
- 乘车人

### 3. 餐饮发票
**提取字段**：
- 发票号码
- 开票日期
- 商家名称
- 金额
- 消费内容

### 4. 酒店发票
**提取字段**：
- 发票号码
- 开票日期
- 酒店名称
- 入住日期
- 离店日期
- 金额

### 5. 机票行程单
**提取字段**：
- 航班号
- 出发机场
- 到达机场
- 起飞时间
- 到达时间
- 金额
- 乘机人

## 工作流

### 步骤 1: 接收 PDF
- 用户发送发票/行程单 PDF 文件
- 支持单张或多张批量发送

### 步骤 2: PDF/图片解析
**PDF 文件** - 使用 `pdftotext` 工具提取文字内容：
```bash
pdftotext <pdf 文件路径> -
```

**图片文件** - 使用 `image` 工具进行 OCR 识别：
```
使用 image 工具分析发票图片，提取文字内容
```

### 步骤 3: 字段识别
根据发票类型识别关键字段：
- 发票类型判断（根据关键词）
- 提取金额、时间、地点等核心信息
- 校验发票与行程单金额是否一致

### 步骤 4: 数据整理
- 按报销人分类
- 按时间排序
- 计算分类汇总

### 步骤 5: 飞书文档更新
使用 `feishu_doc` 工具：
- 创建新文档或追加到现有文档
- 写入 Markdown 表格
- 添加分类汇总

## 工具依赖

### 必需工具
- `pdftotext` (poppler-utils) - PDF 文字提取
- `image` - 图片发票 OCR 识别
- `feishu_doc` - 飞书文档操作

### 可选工具
- `exec` - 执行 PDF 解析命令

## 字段提取规则

### 打车发票关键词
- "电子发票（普通发票）" - 发票类型
- "旅客运输服务" - 服务类型
- "价税合计" - 金额
- "开票日期" - 日期
- "出行人" - 乘车人

### 行程单关键词
- "高德地图—打车——行程单" - 行程单标识
- "上车时间" - 时间字段
- "起点" - 出发地
- "终点" - 目的地
- "服务商" - 平台名称

### 金额校验
- 发票金额 = 行程单金额总和
- 如不一致，标记并询问用户

## 飞书文档格式

### 表格结构
| 序号 | 报销内容 | 上车时间 | 城市 | 起点 | 终点 | 金额 (元) | 报销人 |
|------|----------|----------|------|------|------|-----------|--------|

### 汇总表格
| 报销人 | 金额 (元) | 行程数 | 占比 |
|--------|-----------|--------|------|
| 张三 | 588.48 | 50 | 86.3% |
| 李四 | 93.53 | 10 | 13.7% |
| **合计** | **682.01** | **60** | **100%** |

## 待确认事项

以下情况需要询问用户：
1. **报销人不确定** - 询问"报销人写谁？"
2. **金额不一致** - 标记并询问"发票金额¥XX，行程单金额¥YY，请确认"
3. **字段缺失** - 询问"行程单缺少上车时间，请提供"
4. **发票类型不明** - 询问"这是餐饮发票还是酒店发票？"
