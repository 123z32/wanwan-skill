# 发票整理 Skill

自动整理用户发送的发票和行程单，提取关键信息并生成统计表格。

## 触发条件

当用户发送以下内容时自动触发：
- 打车发票（风韵出行、T3 出行、喜行约车、如祺出行、首汽约车、中交出行等）
- 打车行程单
- 火车票/高铁票
- 机票行程单
- 其他交通报销凭证

## 核心流程

### 1️⃣ 读取票据内容

```bash
# 读取 PDF/OFD 文件内容
读取用户发送的票据文件
提取关键信息：
  - 发票号码
  - 开票日期
  - 行程日期/时间
  - 服务商/车次
  - 起点/出发站
  - 终点/到达站
  - 金额
```

### 2️⃣ 逐项核对（关键！）

```
□ 每个行程单必须逐项列出所有行程
□ 行程单明细金额 = 行程单总额
□ 发票金额 = 行程单总额
□ 总行程数 = 各服务商行程数之和
□ 总金额 = 各行程金额之和
```

**重要**：多行程的行程单必须逐个列出，不得遗漏！

### 3️⃣ 按时间排序

```
按行程日期时间从早到晚排序
同一天按时间先后排序
```

### 4️⃣ 生成表格

**简化版表格（5 列）**：

| 日期 | 时间 | 起点 | 终点 | 金额 |
|------|------|------|------|------|
| 03-09 | 20:39 | 惠州南站 - 北侧 P6 停车场 | 三栋数码工业园 | ¥10.13 |

**完整版表格（7 列）**：

| 序号 | 日期 | 时间 | 服务商 | 车型 | 起点 | 终点 | 金额 |
|:----:|:----------:|:------:|:------:|:------:|:------:|:------:|:------:|

### 5️⃣ 交叉验证

```
1. 读取行程单 → 记录行程数量
2. 逐项列出 → 累加金额
3. 核对总额 → 必须匹配
4. 输出前 → 再次核对总数
```

**输出前必查项**：
```
□ 总行程数是否正确
□ 总金额是否正确
□ 每个服务商的行程数是否匹配
□ 是否有漏项/重复
```

### 6️⃣ 上传到飞书云文档

```
1. 创建/更新飞书云文档《发票行程统计表》
2. 按月份分类（如：2026 年 3 月）
3. 分类统计（打车/火车/飞机）
4. 生成汇总金额
```

## 错误处理

### 常见问题

| 问题 | 解决方案 |
|------|---------|
| PDF 无法读取 | 尝试 OFD 格式或请用户提供截图 |
| 金额不匹配 | 逐项核对行程单明细 |
| 漏掉行程 | 重新核对行程单数量 |
| 重复统计 | 检查发票号码是否重复 |

### 核对清单

每次输出前必须检查：

```
□ 每个行程单的所有行程都已列出
□ 行程单明细金额 = 行程单总额
□ 总行程数 = 各服务商行程数之和
□ 总金额 = 各行程金额之和
□ 没有漏项或重复
□ 按时间正确排序
```

## 飞书云文档配置

### 文档结构

```
📊 发票行程统计表
├── 2026 年 3 月
│   ├── 💰 汇总统计
│   ├── 🚖 打车行程明细
│   └── 🚄 火车行程明细
├── 2026 年 4 月
└── ...
```

### 更新规则

1. 收到新发票后自动更新对应月份
2. 自动重新排序（按时间从早到晚）
3. 自动更新汇总金额
4. 保留历史月份数据

## 注意事项

1. **逐项核对**：多行程的行程单必须逐个列出，不得遗漏
2. **交叉验证**：金额必须匹配，不匹配时立即检查
3. **实时汇报**：处理过程中实时报告进度
4. **分类统计**：打车/火车/飞机分开统计
5. **时间排序**：按行程日期时间从早到晚排序
