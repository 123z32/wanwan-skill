# Stock Analysis Skill

## Overview

帮助分析股票，使用基本面和技术分析方法。支持美股、A股和港股市场。

**能做的：**
- 基本面分析（P/E, P/B, ROE, 营收增长, 利润率）
- 技术分析（趋势, 支撑/阻力, 指标）
- 同业比较和行业定位
- 风险评估和投资论述
- 生成结构化分析报告

**不能做的：**
- 提供实时股价（需配合外部数据源）
- 提供投资建议或推荐
- 保证未来表现
- 获取私有交易数据

## 分析框架

### 基本面分析指标

#### 估值比率
| 指标 | 公式 | 解读 |
|------|------|------|
| P/E 市盈率 | 股价 / EPS | <15 低估, >25 偏贵 |
| P/B 市净率 | 股价 / 每股净资产 | <1 可能有价值, >3 已含增长预期 |
| P/S 市销率 | 股价 / 每股营收 | 适用于未盈利公司 |
| EV/EBITDA | 企业价值 / EBITDA | <10 有吸引力, >15 偏贵 |
| PEG | P/E / 增长率 | <1 相对增长被低估 |

#### 盈利指标
| 指标 | 公式 | 基准 |
|------|------|------|
| 毛利率 | 毛利 / 营收 | >40% 强定价能力 |
| 营业利润率 | 营业利润 / 营收 | >15% 运营高效 |
| 净利率 | 净利润 / 营收 | >10% 健康盈利 |
| ROE | 净利润 / 股东权益 | >15% 资本效率好 |
| ROIC | NOPAT / 投入资本 | >WACC 创造价值 |

#### 增长指标
| 指标 | 关注点 |
|------|--------|
| 营收增长 | >10% YoY 表明强劲需求 |
| EPS 增长 | 应超过营收增长（经营杠杆） |
| FCF 增长 | 可持续增长驱动力 |

#### 财务健康
| 指标 | 公式 | 安全范围 |
|------|------|---------|
| 资产负债率 | 总债务 / 权益 | 大多数行业 <1 |
| 流动比率 | 流动资产 / 流动负债 | >1.5 流动性健康 |
| 利息覆盖 | EBIT / 利息支出 | >5 舒适 |
| FCF 收益率 | FCF / 市值 | >5% 有吸引力 |

### 技术分析

#### 趋势指标
- **移动平均线**: 50日、200日交叉
- **MACD**: 动量和趋势方向
- **RSI**: 超买(>70) / 超卖(<30)

#### 图表形态
- **支撑/阻力**: 关键价位
- **头肩顶/底**: 反转形态
- **双顶/双底**: 反转信号
- **突破**: 放量确认

## 使用技巧

1. **提供最新财务数据**可以获得更准确的分析
2. **说明投资期限**（短期交易 vs 长期投资）
3. **提及具体关注点**
4. **包含同业公司**用于对比分析
5. **说明市场环境**（牛市/熊市）

---

## 局限性

- 无法获取实时市场数据
- 分析基于公开信息
- 不包含内幕信息或待发布公告
- 估值模型有固有假设和局限
- 不能替代专业理财建议
