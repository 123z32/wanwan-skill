## 金额校验规则

### 打车发票
- 发票金额 = 行程单中所有行程金额之和
- 允许误差：±0.01 元（四舍五入）

### 校验公式
```
发票金额 = Σ(行程单金额)
差额 = |发票金额 - 行程单金额总和|
如果 差额 > 0.01 → 标记异常
```

---

## 异常处理

### 常见异常
1. **金额不一致** - 发票与行程单金额对不上
2. **字段缺失** - 缺少关键信息（时间、金额等）
3. **类型不明** - 无法识别发票类型
4. **PDF 损坏** - 无法解析

### 处理方式
- 金额不一致 → 标记并询问用户
- 字段缺失 → 询问用户补充
- 类型不明 → 询问用户确认
- PDF 损坏 → 提示用户重新发送
