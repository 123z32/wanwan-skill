## 🔧 中文字体修复（树莓派容器）

### 问题
- 浏览器渲染中文时显示为方框/乱码
- 原因：Debian 12 容器内未安装任何中文字体

### 安装过程
1. **首次尝试**：`apt-get install fonts-noto-cjk` — 失败，普通用户无 sudo 权限，容器内无 sudo
2. **二次尝试**：从 npmmirror.com 下载 woff2 字体 → 失败，fontconfig 不支持 woff2 格式（需要 TTF/OTF）
3. **最终成功**：下载思源黑体 SC OpenType 格式（`Source Han Sans SC`，16MB `.otf` 文件）

### 安装详情
- **字体文件**: `Source Han Sans SC Regular` (OpenType)
- **安装路径**: `~/.local/share/fonts/font.otf`
- **配置文件**: `~/.config/fontconfig/fonts.conf` — 将 `sans-serif:lang=zh` 优先映射到思源黑体
- **验证**: `fc-list :lang=zh` 返回 `Source Han Sans SC,思源黑体:style=Regular`
- **状态**: ✅ 字体已安装并注册到 fontconfig
- **待办**: 重启 Gateway 后浏览器即可正常显示中文

### 经验教训
- woff2 是网页字体格式，不适用于系统级 fontconfig
- 必须使用 `.ttf` 或 `.otf` 格式
- 无 sudo 环境下，用户级字体目录 `~/.local/share/fonts/` + 自定义 fonts.conf 可行

## 🔤 中文字体最终修复方案（关键发现）

### 问题
- 重启 Gateway 后访问机械革命官网，中文仍显示为方块
- 原因：网页 CSS 指定 `Microsoft YaHei`、`SimHei` 等字体名，浏览器找不到匹配字体

### 根因分析
- 字体文件本身已正确安装（Source Han Sans SC OTF）
- 但 `fontconfig` 没有将网页请求的字体名映射到已安装的字体
- Chromium 按 CSS `font-family` 名称查找，找不到就渲染方块

### 最终解决方案
在 `~/.config/fontconfig/fonts.conf` 中添加**字体别名映射**：

```xml
<match target="pattern">
  <test qual="any" name="family">
    <string>Microsoft YaHei</string>
    <string>SimHei</string>
    <string>SimSun</string>
    <string>Microsoft JhengHei</string>
    <string>FangSong</string>
    <string>KaiTi</string>
    <string>WenQuanYi Micro Hei</string>
    <string>Noto Sans CJK SC</string>
  </test>
  <edit name="family" mode="assign" binding="same">
    <string>Source Han Sans SC</string>
  </edit>
</match>
```

### 经验教训
1. **仅安装字体文件不够** — 必须配置别名映射
2. 网页通常请求 Windows 字体名（微软雅黑、宋体、黑体）
3. Linux 容器需要将 Windows 字体名映射到已安装的开源字体
4. `mode="assign"` + `binding="same"` 确保完全替换，优先级最高

### 验证
- ✅ 机械革命官网中文正常渲染
- `fc-match "Microsoft YaHei"` 应返回 `Source Han Sans SC`

### 时间

### 用户发送

- Python 脚本监听 8086 端口接收 ESP8266 透传的 Modbus 数据
- 备选方案：`socat TCP-LISTEN:8086,fork,reuseaddr -`

### 项目架构
- **ESP8266** → WiFi 透传 → **树莓派 TCP Server (8086)** → OpenClaw 处理 Modbus 协议
- STM32 通过串口连接 ESP8266，ESP8266 做 TCP 透明传输
- 树莓派和 ESP8266 必须在同一局域网

### 注意事项
- ESP8266 固件中配置的 TCP Server IP 必须和树莓派实际 IP 一致
- 不使用 Tailscale IP，必须用局域网 IP (192.168.x.x)
- 防火墙需放行 8086 端口
