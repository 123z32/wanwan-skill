### 解决方案
1. **备份原配置文件**: `/home/wanwanhua/openclaw_data/config/openclaw.json`
2. **修改配置文件**: 移除 browser 部分的 `cdpPortRangeEnd` 参数
3. **验证配置文件**: 确认 JSON 格式正确
4. **重启容器**: 停止并重新启动 openclaw-gateway 容器
