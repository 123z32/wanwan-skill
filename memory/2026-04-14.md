## 🔧 Modbus TCP 透传系统调试（重点）

### 问题背景
- 树莓派（10.74.24.184）作为 TCP Server 监听 8086 端口
- ESP8266（10.74.24.132）作为 TCP Client 连接树莓派
- STM32F407 通过 UART2 连接 ESP8266，Modbus Slave 地址=1
- OpenClaw 容器（172.18.0.2）通过 TCP 连接树莓派发送 Modbus 命令

### 遇到的问题与解决

| # | 问题 | 原因 | 解决 |
|---|------|------|------|
| 1 | 容器内 ping 不通 10.74.24.132 | Docker 网络隔离（172.18.0.x vs 10.74.24.x） | 正常，ESP 主动连接树莓派 |
| 2 | 路径不一致 | 容器内 /home/node/.openclaw/workspace/ vs 宿主机 /home/wanwanhua/openclaw_data/workspace/ | 已记录到 TOOLS.md |
| 3 | v2 服务器 ESP 识别错误 | 10.74.24.132 被识别为客户端而非 ESP | 改用 IP 前缀判断 |
| 4 | 第一条命令成功，后续全部超时 | ESP8266 AT+CIPSEND 后 `> ` 提示符匹配太严格 | 改为 memchr 找 `>` 字符 |
| 5 | v3 客户端断开太快 | 客户端 send 后直接 close，没等响应 | 重写 v3.1，用 threading.Event 等待响应 |
| 6 | 读寄存器 3+ 超时 | Modbus 寄存器映射只实现了 0-2 | 需要在固件中添加传感器寄存器 |
| 7 | ESP 偶尔断开 | 杜邦线接触不良 | 硬件问题，非代码 |
