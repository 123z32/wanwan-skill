## 🎯 项目定位

**RuVector** 是一个**自学习、自优化的向量数据库操作系统**，具有图智能、本地 AI 和内置 PostgreSQL 功能。

> 核心理念：大多数向量数据库只是存储和搜索数据——每次都一样。RuVector 完全不同，它会观察你的使用方式并自动变得更智能。

## 🔥 核心特性 (75 项功能)

### 1️⃣ 自学习与优化
- 🧠 **GNN 图神经网络**: 每次查询都学习，搜索结果随时间改进
- ⚡ **SONA 自优化**: 自动调整路由、排名和压缩以适应工作负载
- 🎯 **46 种注意力机制**: Flash、线性、图、双曲、mincut-gated（减少 50% 计算）
- 🔄 **迁移学习**: 知识跨领域转移，新任务可从过去学习自动启动

### 2️⃣ 图与关系
- 🔗 **完整 Cypher 引擎**: 支持 Neo4j 风格的图查询 `MATCH (a)-[:KNOWS]->(b)`
- 🔬 **8 个验证的图变换器模块**: 物理、生物、流形、时序、经济等
- 🕸️ **超边支持**: 可连接 3+ 节点，原生建模群体关系

### 3️⃣ AI 与计算
- 🤖 **本地 LLM 运行**: 在本地硬件运行 AI 模型（Metal、CUDA、WebGPU），无需云 API
- 📐 **次线性求解器**: O(log n) PageRank、谱方法、稀疏线性系统
- 🧬 **基因组分析**: 变异检测、蛋白质翻译、HNSW k-mer 搜索（12ms）
- ⚛️ **量子相干性**: 通过动态 min-cut 优化进行错误校正

### 4️⃣ 数据库与平台
- 🐘 **PostgreSQL 扩展**: 230+ SQL 函数，可直接替代 pgvector
- 🌐 **随处部署**: 单文件部署到服务器、浏览器、手机、IoT、裸机、WASM（58 KB）
- 🚀 **认知容器**: 单个 `.rvf` 文件 125ms 启动，包含向量、模型、内核
- ⚡ **实时更新**: 即时更新向量和图连接，无需停机

### 5️⃣ 运维与安全
- 🔐 **防篡改审计**: 加密见证链自动记录每个操作
- 🌿 **数据分支**: Git 风格的 COW 分支（1M 向量 +100 编辑 ≈ 2.5 MB）
- 📈 **水平扩展**: Raft 共识、多主复制、自动分片
- 🛡️ **后量子加密**: ML-DSA-65 和 Ed25519 签名

### GNN 工作原理

```
传统向量搜索:
查询 → HNSW 索引 → Top K 结果

RuVector with GNN:
查询 → HNSW 索引 → GNN 层 → 增强结果
                ↑              │
                └──── 学习信号 ──┘
                   (<1ms 适应)
```

**GNN 层三步处理**:
1. **消息传递**: 每个节点从 HNSW 邻居收集信息
2. **注意力加权**: 多头注意力评分哪些邻居最重要
3. **表示更新**: 节点表示根据邻居信息更新

**总延迟**: <1ms（SIMD 加速）
