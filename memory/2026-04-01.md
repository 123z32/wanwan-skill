## 🔍 ESP32-H4 系列芯片查询 (14:32-15:24 UTC)

**用户请求**: "帮我查一下 esp32 h4 系列芯片" → "在国内查找一下"

**来源**: 乐鑫官网 (Espressif)

### 核心定位
新一代 BLE 5.4 双核超低功耗 SoC，支持 Matter-over-Thread

### 无线连接
| 特性 | 规格 |
|------|------|
| 蓝牙 | Bluetooth 5.4 (LE) |
| 802.15.4 | 支持 Thread 1.4 + Zigbee 3.0 |
| 认证 | Bluetooth 6.0 认证 |
| 高级功能 | LE Audio (BIS/CIS)、亚速率连接、PAwR、方向查找 (AoA/AoD) |
| Matter | 支持 Matter-over-Thread |

### 系统性能
| 特性 | 规格 |
|------|------|
| CPU | 32 位 **双核** RISC-V |
| 主频 | 最高 **96 MHz** |
| DSP | 集成 DSP 扩展单元 |
| SRAM | 384 KB |
| ROM | 128 KB |
| 外部存储 | 支持 PSRAM 扩展 |

### 低功耗设计
- 集成 DC-DC 转换器 - 提升电源效率
- 多种低功耗模式 - 可选外设开关
- 适合电池供电 - 纽扣电池/充电电池即可长时间运行
- 硬件优化 - 支持无 CPU 参与定期广播

### 安全机制
- 安全启动
- 存储器加密
- 真随机数发生器
- 硬件加密加速器
- ECDSA 数字签名外设

### 外设接口
| 接口 | 数量/支持 |
|------|----------|
| GPIO | 多达 40 个 |
| 触摸感应 | 15 个 GPIO |
| 标准接口 | I2C, I2S, SPI, UART, ADC, 定时器, DMA |
| 特殊接口 | TWAI (CAN), USB-OTG, MCPWM |
| 事件任务矩阵 | ETM (自动触发任务) |

### 软件生态
- ESP-IDF - 完全支持
- ESP-BLE-MESH - 蓝牙 Mesh
- ESP-BLE-AUDIO - 蓝牙音频
- ESP-Matter - 计划支持
- ESP-AT / ESP-Hosted - 将适配（网络协处理器模式）

### 适用场景
- 可穿戴设备
- 蓝牙低功耗音频配件
- Matter-over-Thread 设备
- 电池供电传感器
- 触摸面板/智能开关
- 室内定位 Beacon

**待确认**: 用户具体想用 H4 做什么项目

## 🔧 树莓派 + STM32 串口通信方案讨论 (15:39-15:49 UTC)

**用户提议**: "你觉得让你控制树莓派通过串口跟 stm32 通信，然后来控制或者读取一些传感器怎么样"

### 方案架构
```
树莓派 5 (Linux/OpenClaw) ←UART 串口→ STM32 (MCU) ←I2C/SPI/GPIO→ 传感器
```

### 优势评估
| 优势 | 说明 |
|------|------|
| 实时性好 | STM32 负责实时采集，树莓派负责上层逻辑 |
| 稳定性高 | MCU 抗干扰能力强，适合工业环境 |
| 成本低 | STM32 便宜，传感器直接接 MCU |
| 隔离保护 | 传感器侧的电气问题不会烧树莓派 |
| 扩展灵活 | STM32 可以接多个传感器，树莓派只发指令 |

### 技术实现要点

**1. 硬件连接**
- 树莓派 GPIO UART → STM32 USART
- TX → RX, RX → TX, GND → GND

**2. 通信协议选项**
- 自定义串口协议（帧头 + 命令字 + 数据长度 + 数据+CRC+ 帧尾）
- Modbus RTU（之前 SCADA 项目已有经验）

**3. 树莓派端代码**
```python
import serial
ser = serial.Serial('/dev/ttyAMA0', 115200, timeout=1)
```

**4. OpenClaw 集成**
- 可开发串口控制 skill
- 支持飞书消息触发指令

### 适用场景
- 工业传感器（温湿度、压力、流量）
- 需要实时响应的控制（电机、继电器）
- 多传感器数据采集
- 长距离通信

### 待确认
- 用户具体想做什么类型的项目（数据采集/控制系统/工业 SCADA）
- 具体传感器类型

**用户确认**: "你说一下，然后你就可以控制传感器什么的"

### 完整方案架构

```
用户 (飞书消息) → 绾绾 (OpenClaw) → 树莓派 5 (Python 串口) → STM32 (MCU) → 传感器/执行器
```

### 硬件清单
| 设备 | 型号/规格 | 数量 |
|------|----------|------|
| 树莓派 5 | 8GB RAM + 128GB SSD | 1 (已有) |
| STM32 | F103/F407/H743 | 1 (待确认型号) |
| 传感器 | DHT11/DS18B20/MPU6050 等 | 若干 (待确认) |

### 通信协议设计
**帧格式**: `[帧头 0xAA] [命令字 1 字节] [数据长度 1 字节] [数据 N 字节] [CRC16 2 字节] [帧尾 0x55]`

**常用命令**:
- 0x01: 读取温度
- 0x02: 读取湿度
- 0x03: 读取加速度
- 0x10: 打开继电器
- 0x11: 关闭继电器
- 0xFF: 心跳/测试

### 软件实现
1. **STM32 端** (C 语言) - 串口中断接收 → 解析协议 → 执行命令 → 返回结果
2. **树莓派端** (Python) - serial 模块，/dev/ttyAMA0, 115200 波特率
3. **OpenClaw Skill** (TypeScript) - 监听飞书消息 → 发送串口命令 → 返回结果

### 实现步骤
1. 硬件连接 - 树莓派 UART ↔ STM32
2. STM32 固件 - 写串口协议 + 传感器驱动
3. 树莓派服务 - Python 串口通信脚本
4. OpenClaw Skill - 集成到绾绾
5. 测试联调 - 飞书发消息 → 读取传感器

### 待确认事项
1. STM32 型号 - 用户手上有什么型号？
2. 传感器类型 - 想先测什么？
3. 通信方式 - 树莓派 GPIO 串口还是 USB 转串口？
