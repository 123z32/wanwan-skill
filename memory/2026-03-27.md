## 🐛 遇到的问题 + 教训

### 问题：edit 工具死循环（17:00 左右）

**经过**：尝试修正 MEMORY.md 交流规则编号重复问题，edit 工具匹配失败后重复调用 100+ 次

**根本原因**：
1. 目标锁定过窄——专注于"修复编号"，忽略方法已失效
2. 缺乏失败计数——没有记录重试次数，应在 3-5 次后换方法
3. 错误分析不足——edit 返回的错误包含实际文件内容，但未仔细对比差异
4. 工具策略单一——只会用 edit，没想到用 read 确认或 write 重写
5. 元认知缺失——没有问自己"这个方法试了很多次，要不要换思路？"

**教训**：
> 这是典型的**固执型错误**——在方法失效时继续重复，而不是退一步重新评估。
> 
> **正确流程**：失败 1 次→读取文件确认实际内容 → 失败 2 次→换 write 工具或更小片段匹配 → 失败 3 次→暂停并询问用户
