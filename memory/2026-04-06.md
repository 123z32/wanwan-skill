### 2. Firecrawl 自部署失败 🔴
- **问题**: 容器启动后反复重启，健康检查失败
- **根本原因**: 
  - Firecrawl 容器需要自动运行数据库迁移来创建表结构
  - 但容器内没有实现迁移逻辑，环境变量 `NUQ_RUN_MIGRATIONS` 和 `RUN_MIGRATIONS` 均无效
  - 容器内没有 `package.json`、Prisma schema 或 SQL 迁移文件
- **已尝试方案**:
  1. ✅ 添加 PostgreSQL (pgvector) - 成功
  2. ✅ 添加 Redis - 成功
  3. ✅ 添加 RabbitMQ - 成功
  4. ❌ 设置 `NUQ_RUN_MIGRATIONS=true` - 无效
  5. ❌ 设置 `RUN_MIGRATIONS=true` - 无效
  6. ❌ 手动执行 `npm run db:migrate` - 失败（无 package.json）
  7. ❌ 手动执行 `npx prisma migrate deploy` - 失败（无 schema 文件）
- **下一步**:
  - 查看官方文档确认正确部署方式
  - 或联系 Firecrawl 官方支持
  - 或考虑使用 hosted 版本 (firecrawl.dev)

## 🔧 Firecrawl 部署配置（供参考）

```yaml
services:
  postgres:
    image: pgvector/pgvector:pg16
    environment:
      POSTGRES_DB: firecrawl
      POSTGRES_USER: firecrawl
      POSTGRES_PASSWORD: firecrawl_password
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U firecrawl"]
      interval: 5s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine

  rabbitmq:
    image: rabbitmq:3-management-alpine
    environment:
      RABBITMQ_DEFAULT_USER: firecrawl
      RABBITMQ_DEFAULT_PASS: firecrawl_password

  app:
    image: ghcr.io/firecrawl/firecrawl:latest
    ports:
      - "3002:3002"
    environment:
      - REDIS_URL=redis://redis:6379
      - NUQ_DATABASE_URL=postgresql://firecrawl:firecrawl_password@postgres:5432/firecrawl
      - NUQ_RABBITMQ_URL=amqp://firecrawl:firecrawl_password@rabbitmq:5672
      - NO_AUTH=true
```
