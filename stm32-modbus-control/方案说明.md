## 🎯 项目目标

通过飞书消息远程控制 STM32F407VGT6 开发板的 LED 和继电器（风扇），通信链路：

```
┌─────────┐    飞书消息    ┌──────────┐  Modbus ASCII  ┌─────────┐
│  张     │ ────────────→ │  绾绾    │ ──────────────→ │ STM32   │
│ (飞书)  │               │(树莓派 5)│   (115200)     │(SkyStar)│
└─────────┘               └──────────┘                └─────────┘
```

## 🔌 硬件连接

### 方案 A：USB 转 TTL 模块（推荐，简单可靠）

```
USB-TTL 模块        STM32F407VGT6 (SkyStar)
────────────        ─────────────────────
TX (绿色)      ←→   PA3 (USART2_RX)
RX (黄色)      ←→   PA2 (USART2_TX)
GND (黑色)     ←→   GND
5V (红色)      ←→   5V (可选，模块供电)
```

**所需材料**：
- USB 转 TTL 模块 × 1（CH340/CP2102/FT232 均可）
- 杜邦线 × 4

### 方案 B：树莓派 GPIO UART

```
树莓派 5 GPIO       STM32F407VGT6 (SkyStar)
─────────────       ─────────────────────
GPIO 14 (TXD)  ←→   PA3 (USART2_RX)
GPIO 15 (RXD)  ←→   PA2 (USART2_TX)
GND (Pin 6)    ←→   GND
```

**注意**：树莓派 5 需启用串口（`/boot/config.txt` 添加 `enable_uart=1`）

## 📡 通信协议：Modbus ASCII

### 协议参数

| 参数 | 值 |
|------|-----|
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | None (N) |
| 停止位 | 1 |
| 模式 | Modbus ASCII |
| 从站地址 | 0x01 |
| 帧结束符 | `\r\n` (CR+LF) |

### 寄存器映射表

| 寄存器地址 | 功能码 | 名称 | 类型 | 读写 | 说明 |
|-----------|--------|------|------|------|------|
| 0x0000 | 03/06 | LED0 控制 | 保持寄存器 | R/W | 0=OFF, 1=ON |
| 0x0001 | 03/06 | LED1 控制 | 保持寄存器 | R/W | 0=OFF, 1=ON |
| 0x0002 | 03/06 | 风扇控制 | 保持寄存器 | R/W | 0=OFF, 1=ON |
| 0x0010 | 03 | 系统状态 | 输入寄存器 | R | 位0=LED0, 位1=LED1, 位2=FAN |

### 命令示例

**1. 打开 LED0**
```
发送：:010600000001F9CR
接收：:010600000001F9CR
```

**2. 关闭 LED0**
```
发送：:010600000000FACR
接收：:010600000000FACR
```

**3. 读取 LED0 状态**
```
发送：:010300000001FBCR
接收：:010302000159CR  (LED0=ON)
```

**4. 读取系统状态（所有设备）**
```
发送：:010300100001EBBR
接收：:010302000555CR  (LED0=ON, LED1=OFF, FAN=ON)
```

### LRC 校验计算

LRC（纵向冗余校验）计算示例：
```
地址：01, 功能：06, 数据：00 00 00 01
求和：01 + 06 + 00 + 00 + 00 + 01 = 0x08
取反：~0x08 + 1 = 0xF8
LRC = 0xF8 (但实际是 0xF9，因为 Modbus ASCII 用 2 的补码)
```

**简单算法**：
```python
def calc_lrc(data_bytes):
    return ((~sum(data_bytes) + 1) & 0xFF)
```

## 🛠️ 开发任务清单

### 任务 1：STM32 固件开发（Claude Code 负责）

**工具**：STM32CubeIDE + FreeModbus

**步骤**：
1. 用 STM32CubeMX 配置项目：
   - MCU: STM32F407VGT6
   - USART2: Asynchronous (PA2/PA3), 115200, 8N1
   - GPIO:
     - PF9: GPIO Output (LED0)
     - PF10: GPIO Output (LED1)
     - PF8: GPIO Output (继电器/FAN)
   - SYS: Debug → Serial Wire

2. 集成 FreeModbus 库：
   - 下载：https://github.com/armink/FreeModbus
   - 移植到 STM32（参考 `port` 目录）
   - 配置 `modbus_config.h`：
     ```c
     #define MB_SLAVE_ADDRESS 1
     #define MB_PORT_UART USART2
     #define MB_UART_BAUDRATE 115200
     ```

3. 实现寄存器回调：
   ```c
   eMBErrorCode eMBRegHoldingCB(UCHAR *pucRegBuffer, USHORT usAddress,
                                USHORT usNRegs, eMBRegisterMode eMode)
   {
       if (usAddress == 0x0000) {  // LED0
           if (eMode == MB_REG_WRITE) {
               LED0 = (pucRegBuffer[0] != 0) ? ON : OFF;
           } else {
               pucRegBuffer[0] = LED0;
           }
       }
       // ... 其他寄存器
   }
   ```

4. 编译烧录测试

### 任务 2：树莓派 Modbus 客户端（绾绾负责）

**依赖**：
```bash
pip install pymodbus
```

**核心代码**：
```python
from pymodbus.client import ModbusSerialClient

class STM32Controller:
    def __init__(self):
        self.client = ModbusSerialClient(
            port='/dev/ttyUSB0',
            baudrate=115200,
            parity='N',
            stopbits=1,
            bytesize=8,
            timeout=1
        )
        self.client.connect()
    
    def led_on(self, led_id=0):
        self.client.write_register(led_id, 1, slave=1)
    
    def led_off(self, led_id=0):
        self.client.write_register(led_id, 0, slave=1)
    
    def fan_on(self):
        self.client.write_register(2, 1, slave=1)
    
    def fan_off(self):
        self.client.write_register(2, 0, slave=1)
    
    def get_status(self):
        result = self.client.read_input_registers(0x0010, 1, slave=1)
        return result.registers[0]
```

## ⚠️ 注意事项

1. **串口极性**：TX 接 RX，RX 接 TX（交叉连接）
2. **共地**：树莓派和 STM32 必须共地（GND 相连）
3. **电平匹配**：STM32 是 3.3V 电平，USB-TTL 需支持 3.3V
4. **Modbus 超时**：设置合理超时（1 秒），避免阻塞
5. **LRC 校验**：务必正确计算，否则 STM32 会丢弃帧
